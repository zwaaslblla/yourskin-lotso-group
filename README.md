# YourSkin -lotso group-

Create a modern skincare web application called YouSkin.

Design style:

Soft pink, cream, and white color palette.

Elegant and feminine UI.

Rounded cards and smooth animations.

Floral aesthetic with small sakura/cherry blossom petals.

Login Flow:

User enters email and password.

After successful login, display a fullscreen popup animation.

The popup contains blooming flowers and falling sakura petals.

Show text: "Welcome to YouSkin 🌸" "Your personal AI skincare assistant"

Add a smooth fade-in and scale animation.

Popup automatically closes after 3 seconds.

Dashboard Animation:

Floating flower petals continuously move across the screen.

Decorative flower elements in the corners.

Soft glowing effects.

Smooth page transitions.

Home Page Features:

Upload face photo.

AI skin analysis button.

Analysis results.

Skincare recommendations.

Analysis history.

Make the application feel cute, elegant, aesthetic, and professional.
Add a special flower bloom animation every time the user opens the application.

When the dashboard loads:

A flower blooms in the center.

Petals scatter softly around the screen.

The animation lasts 2-3 seconds.

Then the dashboard appears smoothly.
